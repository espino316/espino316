## How I think about products

**Platform over point solution.** Build capabilities that unblock multiple teams, not one feature for one requester.

**Data contracts before dashboards.** Quality, ownership, and SLAs get defined first. Everything downstream inherits those decisions.

**AI as a shipped feature, not a demo.** Real acceptance criteria, guardrails, and a human in the loop. A prototype that impresses in a meeting and fails in production is a liability.

**Delivery is part of the product.** Release cadence, test automation, and honest success metrics shape the user's experience as much as the interface does.
